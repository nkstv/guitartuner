Extension Chrome · Gratuite

Accorde plus vite.
Directement dans Chrome.

Guitar Tuner Fast place l'accordeur dans une fenêtre Chrome compacte. Choisis guitare acoustique, électrique, basse ou ukulélé, puis écoute les notes de référence ou utilise ton microphone sans ouvrir un nouvel onglet.
